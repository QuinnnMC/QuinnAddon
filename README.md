# Quinn Addon
## Made Specifically For 6b6t.org


## Modules

### Anti-Phase
Places the configured blocks at the feet of your enemy to prevent them from placing web/fire to phase into a block.

### Liquid Filler
Works like the base Meteor Module, but has these new features;  
-Pause While Eating/using items  
-Now shows where it last placed a block by rendering a cube there  

### Speed 
Now recoded to work a bit better with the anti-cheat. Added these features;  
-Configurable speed on the ground (ranges from 0.1-5.8) which is 7.8 BPS  
-Configurable speed in the air (ranges from 0.1-6.6) which is 7 BPS but i recommend 5.2  
-Configurable speed in Lava (ranges from 0.1-1.6) which is 2 BPS  
-Configurable speed in cobwebs (ranges from 0.1-4.5) which is 1.6 BPS  
-Configurable speed while sneaking (ranges from 0.1-4.1) which is 5.6 BPS but you might rubberband when not using swift sneak  
-Water movement not affected by speed (2 BPS without depth strider III and 3.6 with)  
-Soul sand speed (currently broken without soul speed boots but with them you walk at 9 BPS)  

### Auto-Web
Now recoded to be a bit better. Added these features;  
-Pause while eating/drinking  
-Now renders a cube where it placed webs  

### Bedrock Nuker
Mines bedrock around the player, has a flatten option and a range slider. (currently only breaks when in a GUI such as chat, inventory, pause ect.)

### Auto-Mine
This was an attempt at moving BlackOut's Auto-Mine code/module to allow some extra features, but as of right now it does not work so I might end up removing it.
